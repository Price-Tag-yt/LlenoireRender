# Third-party components

## Zalith RendererPlugin-v2 architecture
This project follows the public RendererPlugin-v2 configuration contract and Android manifest metadata documented by ZalithLauncher. No Zalith source code is bundled.

## Android / Android Gradle Plugin
The build uses Android SDK/NDK tooling and the Android Gradle Plugin. These remain under their respective licenses.

## Renderer research references
HolyGL4ES, FCL Holy-GL4ES and MobileGlues were studied as architectural references. This repository does not copy their source code. MobileGlues is LGPL-2.1; its license is intentionally not applied to this original codebase because MobileGlues sources are not bundled.
