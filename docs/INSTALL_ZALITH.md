# Install in Zalith Launcher

1. Build/download the APK from GitHub Actions.
2. Install the plugin APK on Android.
3. Open Zalith Launcher.
4. Open the renderer selection for the Minecraft 1.12.2 instance.
5. Select `LlenoireRender 1.12.2` if the launcher exposes the plugin.
6. Start with the `BALANCED` profile and MSAA `0`.
7. Test vanilla 1.12.2 before Forge/modpacks.
8. If the game fails, collect the launcher log and the renderer log before changing several variables at once.

Because renderer-plugin APIs can change, exact UI labels are intentionally not claimed here beyond the public V2 contract.
